# Eurobarometer Longitudinal Analysis — Extended (4 waves, 2012–2024)

**Author:** Camilla Bonomo  
**Extends:** Gnambs & Appel (2019) — *The impact of social robots on public attitudes toward robotics in Europe*

---

## Overview

This project replicates and extends Gnambs & Appel's (2019) longitudinal multilevel analysis of European attitudes toward robots and artificial intelligence, using four Eurobarometer survey waves (2012, 2014, 2017, 2024). The main contributions are:

- **Longitudinal replication and extension** of the G&A two-level model (Models A1–A2) across all four waves, using `rob2item` (rob1 + rob2) as the comparable two-item composite enabling direct cross-wave comparison
- **Italy 2024 focus**: longitudinal trajectory, residual analysis, demographic subgroup comparisons, and a new **bidimensional decomposition** of wave-4 attitudes into `rob2024_pos` (social utility) and `rob2024_neg` (absence of job-loss threat)
- **SP554 exploratory module**: five new indicators derived from ZA8844 battery items (AI workplace exposure, regulation demand, digital self-efficacy, tech pessimism, employer communication) with mediation and stratification analyses on the Italian subsample

Hofstede cultural dimensions (UAI, PDI, IDV, MAS, LTO, IVR) were explored as country-level predictors but are **not part of the final inferential pipeline**: UAI showed p = 0.304 in the full four-wave model with 0.0% reduction in L2 variance vs. Model A2. All Hofstede model code is retained in `syntax/archive/` for methodological transparency.

The United Kingdom is excluded from all analyses for cross-wave consistency (absent from wave 4 post-Brexit).

## Analysis Pipeline

Set the working directory to `project/` before running any script:

```r
setwd("path/to/project")
```

Scripts must be run in order. Each script sources `0_Start.R` and loads `dat.Rdata` independently, so they can also be rendered individually.

| Step | Script | Description | Runtime |
|------|--------|-------------|---------|
| 0 | `0_Start.R` | Helper functions (auto-sourced) | — |
| 1 | `1_Load_data_extended.R` | Load raw data, recode variables, run MICE (m=20) | ~30–60 min |
| 2a | `2_1_Descriptives_extended.R` | Descriptive stats, omega reliability, bidimensional CFA | ~5 min |
| 2b | `2_2_Measurement_invariance_extended.R` | Configural → scalar CFA across waves | ~10 min |
| 3 | `3_Current_and_changes_extended.R` | Weighted means, t-tests, attitude change | ~5 min |
| 4 | `4_Predictors_extended.R` | Multilevel models A0–A2, Italian residuals (rob, rob2item) | ~15 min |
| 4b | `4b_Italy_2024_focus.R` | SP554 indicator construction, correlations, mediation | ~20 min |
| 5 | `5_Plots_extended.R` | Figures 1–4, 7–16 | ~20–30 min |
| 5b | `5b_Italy_2024_plots.R` | Figures 17–20 (SP554 focus) | ~15 min |
| 6 | `6_Document_results_extended.R` | Render all scripts to HTML | cumulative |

To render all scripts to HTML at once, run script 6. **If `data/dat.Rdata` already exists, MICE is skipped automatically** in script 1 (the most time-consuming step).

## Key Variables

### Dependent variables

| Variable | Description | Range | Waves |
|----------|-------------|-------|-------|
| `rob` | Three-item composite (rob1+rob2+rob3) | 0–9 | 1–3 only |
| `rob2item` | Two-item comparable composite (rob1+rob2) | 0–6 | 1–4 |
| `rob2024_pos` | Wave-4 utility subscale (rob2+rob3) | 0–6 | 4 only |
| `rob2024_neg` | Wave-4 threat-absence subscale (r24_c+r24_d) | 0–6 | 4 only |

`rob3` wording changed in wave 4 ("boring/repetitive" vs. "hard/dangerous"), rendering `rob` non-comparable across all four waves. All cross-wave analyses use `rob2item`. Psychometric validation (Script 2_1) rejected a single-factor structure for the four-item wave-4 composite (CFI < .95, RMSEA > .06), motivating the two-subscale solution.

### Level-1 (individual) predictors

| Variable | Description | Coding |
|----------|-------------|--------|
| `sex` | Gender | 0 = male, 1 = female |
| `age` | Age (centred, unit = 10 years) | continuous |
| `educ` | Education (age at end of full-time education, centred) | continuous |
| `white` | Employment type | 1 = white-collar, 2 = blue-collar, 3 = non-employed |

### Level-2 (country) predictors — Model A2

| Variable | Description |
|----------|-------------|
| `AGEOLD` | Population aged 65+, % |
| `TECHEXP` | High-tech exports, % of manufactured exports |
| `INVEST` | Mean z-score of R&D expenditure and researchers in R&D |
| `UNEMP` | Unemployment rate |
| `LAT`, `LONG` | Country geographic coordinates |

### SP554 indicators (Script 4b — Italy focus, wave 4)

| Indicator | Source items | Description | Range |
|-----------|-------------|-------------|-------|
| `ai_exposure_2024` | QB7_1–6 | Count of AI workplace activities experienced | 0–6 |
| `regulation_demand_2024` | QB11_1–5 | Mean importance of AI regulation rules | 0–3 |
| `digital_self_efficacy_2024` | QB2_1 + QB2_4 | Confidence in digital skills | 0–3 |
| `tech_pessimism_2024` | QB1_1–4 | Perceived negative impact of digital tech | 0–3 |
| `employer_communication_2024` | QB9_1–7 | Employer informed about AI use (binary) | 0/1 |

## Notes

- **MICE**: Multiple imputation uses m=20 datasets, CART method, fixed seed (42). `rob`, `rob2item`, `rob2024_pos`, `rob2024_neg` are passive composites recomputed after each iteration. SP554 indicators (QB1, QB2, QB7, QB9, QB11) are added post-hoc by merging raw ZA8844 values via `pid` — they are not re-imputed.
- **Wave 4 limitations**: `feel1`–`feel4` items are not available on a comparable 1–10 scale in wave 4. `rob3` wording changed in 2024, making it non-comparable. The gender variable in wave 4 includes a non-binary option (N = 49), coded NA.
- **Croatia (HR)**: Absent from wave 1 (2012); excluded for that wave only.
- **Hofstede dimensions**: Merged into `cntry_data` and `dati` for descriptive and contextual use (e.g., Italy UAI = 75 cited in the written text). They are **not used as inferential predictors** in the final models.
- **rob2024_pos / rob2024_neg**: The one-factor CFA for the four-item wave-4 composite was rejected (CFI = 0.759, RMSEA = 0.577). A two-factor solution (utility vs. threat-absence) with positive inter-factor correlation is adopted for all inferential analyses.
